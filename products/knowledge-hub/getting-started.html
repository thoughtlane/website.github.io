Getting started

Add materials, ask with sources, assign courses to sections, and build learning paths.

Staff path

  1. Open Files. Upload a PDF or Office file once, or use Open from drive to link a school drive file by reference (admins configure drives under Administration → External drives). The row says Waiting, then Reading, Splitting into chunks, and Saving. Search works when it says Ready to search. You can leave the page.
  2. Select that file and Chat with this file. This product is self-study. Lessons, quizzes, and class assignment are in Socratic Dialogue.
  3. Open Search. Ask a question. Read the answer and open the cited sources to confirm.
  4. For a class, switch to Teacher's Assistant (Socratic Dialogue) → Files. Make a lesson, multiple choice, or fill-in, then assign the section. Do not do that here.
  5. School notices from Administration → Announcements appear as a banner when active.
  6. Use in-app Help anytime (includes Home). Send Feedback from the header if something is unclear.

Learner path

  1. Open Search to ask about materials your school has shared. Always check the cited sources.
  2. Assigned class lessons and quizzes open in Socratic Dialogue, not here.
